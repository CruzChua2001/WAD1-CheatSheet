# Cheat Sheet Search Engine

Lightweight local search for Web Application Development (Node, Express, HTML, JS) open-book use.

## Run

```bash
npm install -g vite
npm install
npm run dev
```

Open the URL shown in the terminal (e.g. http://localhost:5173) in your browser.

## Build (static)

```bash
npm run build
```

Output is in `dist/`. Serve that folder to run without Node (e.g. open `dist/index.html` or use any static server).
